# Жильберта

Локальный ИИ-агент с внутренней моделью мышления, долгосрочной памятью и рефлексией.

## Что умеет

- **Память** — помнит все сообщения, извлекает факты о пользователе
- **Убеждения** — формирует и хранит свои мнения по темам (`/teach`, `/reflect`)
- **Рефлексия** — каждые 25 сообщений анализирует диалог и генерирует внутренние мысли
- **Любопытство** — предлагает темы для изучения на основе частых обсуждений
- **Ассоциации** — связывает темы между собой через общие теги
- **Streamlit UI** — веб-интерфейс для визуализации внутреннего состояния
